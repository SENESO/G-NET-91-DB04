# G-NET-91-DB04 — Database Assignment (Session 04)

SQL Server database implementations based on the provided ERDs.

## Databases

| File | System | Tables |
|------|--------|--------|
| `01-OnlineRetailStore.sql` | Online Retail Store Management System | 12 |
| `02-HotelReservationSystem.sql` | Hotel Reservation Management System | 13 |

## How to run

1. Open SQL Server Management Studio (SSMS)
2. Open the `.sql` file
3. Press `F5` to execute

Each script creates its database, all tables with primary keys
and foreign keys, then runs the Part 02 insert/update operations.
